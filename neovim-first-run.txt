This version runs inside a sandbox and can't see the compilers, language
servers and tools installed on your system.

Your config goes in ~/.var/app/@FLATPAK_ID@/config/nvim

To add Node.js, Rust, Go and others, install SDK extensions and enable them:

  $ flatpak install flathub org.freedesktop.Sdk.Extension.node24
  $ flatpak override --user --env=FLATPAK_ENABLE_SDK_EXT=node24 @FLATPAK_ID@

Use `flatpak search Sdk.Extension` to find others.
